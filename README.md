# МТС Energytool

Конкурсная реализация консультанта Energytool для пакетной обработки диалогов. Скрипт читает вопросы из CSV, ищет релевантные разделы базы знаний и формирует ответы через прокси модели. Веб-чат и сохранение сессий запланированы.

## Локальная проверка

Понадобится Python 3.11 или новее. CSV-скрипт использует стандартную библиотеку Python.

```bash
python -m unittest discover -s tests -v
python tools/build_submission.py
```

Сборка создаёт `dist/energytool-submission.zip`. В конкурсном архиве лежат только корневые модули Python и `requirements.txt`. Входные данные предоставляет платформа.

Если у вас есть локальные материалы кейса, можно проверить входные файлы без доступа к модели:

```bash
python submission/solution.py --questions questions.csv --kb knowledge-base.zip --validate-only
```

Для генерации уберите `--validate-only`. Платформа передаёт URL прокси, ключ и точный идентификатор модели через окружение. Результат записывается в `submission.csv` в UTF-8 с колонками `id,answer`. Подробности в [документации CSV-скрипта](submission/README.md).

## Как предложить изменения

Создайте ветку от `main` в своём форке, например `feature/web-chat` или `fix/csv-validation`, и откройте pull request в `main`. В описании укажите, что изменилось и какие проверки выполнены.

Ветки в основном репозитории ведёт владелец. Изменения в `main` проходят через pull request, который объединяет владелец.

Храните базу знаний, исходные материалы кейса, демоданные, отчёты поиска и ключи локально. Для тестов используйте синтетические данные.
