# Кандидат context-v1

Первая согласованная версия улучшений: использование найденных источников и восстановление неполной генерации. Без эмбеддингов; реранкер не включен по умолчанию; основной промпт сохранен.

## Изменения
- Квота разделов на файл удалена. Консервативное удаление повторов одинакового текста/слов в контексте одного продукта; различающиеся условия, числа и отрицания сохраняются.
- Расширенный пул: max(36, TOP_K*3), максимум 100. Основных источников TOP_K (обычно 12); до двух релевантных разделов ограничений добавляются без вытеснения основных. Первые три основных источника идут первыми, затем ограничения и остальные основные источники. Общий бюджет 40 000 символов. Пропуски отражаются счетчиком, но абсолютная полнота при переполнении не гарантируется.
- Полные заголовки сохраняются в генерации и входе реранкера.
- При length/пустом тексте одна логическая повторная генерация до 100 слов с теми же документами при оставшемся времени >=12 секунд. Используется существующее ограничение MAX_TOKENS, оно не увеличивается. Транспортные повторы остаются ограниченными общим дедлайном. Исходный текст хранится до получения непустого завершенного ответа. При повторном обрыве/ошибке сохраняется пригодный исходный текст, который может остаться неполным. Пустой финальный текст после восстановления — техническая ошибка. Рассуждения не публикуются.

## Проверка
43 unit/integration-теста прошли. Проверены длина, CSV, ZIP, дедлайн, различия условий, дополнение источников, завершенный ответ без лишнего вызова, восстановление, повторный обрыв, ошибка восстановления, недостаток времени и скрытые рассуждения.
Сравнение фактических запросов (не ответов LLM) на 18 демовопросах + 8 дополнительных сценариях: исходная версия 33/33 группы, кандидат 33/33; полностью покрыты 26/26 сценариев. Максимальный размер пользовательского сообщения кандидата в замере 18 831 символ. Покрытие не является независимым доказательством качества: набор уже использовался в разработке.
Первый вариант добавления ограничений дал 32/33: оговорка вытеснила связку продуктов в сценарии 15. Этот вариант исправлен: дополнительные ограничения больше не занимают места основных источников.
