## Применяется ли 1.5

- В распакованном архиве при пустом окружении `config.reload()` даёт `W_DENSE=1.5`, `M_DENSE_MISMATCH=0.7`.
- Переопределить значение можно только переменной `ET_W_DENSE` (у W_DENSE нет устаревших синонимов,
  вызовов `config.override` в коде архива нет). При проверке переменных `ET_*` в окружении не было.
- Проверка на реальном слиянии оценок (`retrieval.Search.find`, политика `weighted`): для 594 пар
  «кандидат при 1.5 / тот же кандидат при 3.0» разность оценок равна (1.5 − 3.0) × нормированное
  dense-сходство, умноженное на 1 или на 0.7 (раздел чужого продукта). Расхождений 0.
